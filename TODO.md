# GitPilot Control Room outcomes

- [x] Show completed contributions with repository, contribution type, branch/PR, verification state, and evidence summary.
- [x] Show active and working contributions with current state, agent progress, elapsed time, and next action.
- [x] Provide approval controls before external repository changes and make approval status explicit.
- [x] Show test, security, review, and pull-request evidence without claiming success from model output alone.
- [x] Provide repository and opportunity views with search/filter controls.
- [x] Provide provider health and model configuration status.
- [x] Provide add/edit/rotate/disable provider-key controls where values are write-only and masked after save.
- [x] Keep Gmail optional for notifications and never request or store a Gmail password.
- [ ] Connect the dashboard API adapter to the deployed GitPilot gateway URL.
- [ ] Add production authentication/role checks and durable database-backed settings.
- [ ] Publish the dashboard to the user's specified GitHub repository.
